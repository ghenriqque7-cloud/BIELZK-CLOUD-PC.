# BIELZK CLOUD PC 💻

Meu projeto de PC virtual Windows.

## Programas desejados
- Roblox
- Roblox Studio
- Discord

## Configuração desejada
- Windows 10 ou 11
- 16 GB de RAM
- 100 GB de armazenamento
- 4 a 8 núcleos de CPU
- Placa de vídeo com aceleração gráfica

## Objetivo
Criar um ambiente virtual para jogar Roblox
e desenvolver jogos no Roblox Studio.
