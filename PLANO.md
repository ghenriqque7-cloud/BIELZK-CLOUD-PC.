# PLANO DO BIELZK CLOUD PC

## Objetivo
Ter um computador Windows na nuvem.

## Programas
- Roblox
- Roblox Studio
- Discord

## Requisitos desejados
- 16 GB de RAM
- 100 GB de armazenamento
- 4 núcleos ou mais
- GPU com aceleração gráfica
- Windows 10 ou 11

## Etapas
1. Encontrar um serviço de PC na nuvem.
2. Verificar se oferece Windows e GPU.
3. Verificar se permite instalar Roblox.
4. Testar o desempenho.
5. Configurar Discord e Roblox Studio.

## Observação
O GitHub guarda os arquivos do projeto.
Ele não hospeda o computador virtual.
